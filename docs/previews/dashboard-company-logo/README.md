34 tests Django sur PostgreSQL 14.24, 180 contrôles navigateur FR/EN à 1440/390/320 px et 12 mesures comparatives réussis. Les images conservent leurs proportions sans suragrandissement des petits fichiers ; le nom reste affiché dans tous les états. Les formulaires, liens, langues et actions sont conservés, avec des cibles tactiles d'au moins 44 px de haut sur mobile.

`demo@example.invalid` est seulement une donnée de prévisualisation, pas une valeur du produit ni un compte réel.
