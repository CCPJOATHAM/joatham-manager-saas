# Captures de l'accueil public

Rendus locaux du template Django, avec les forfaits officiels de repli et les traductions FR/EN du projet. Aucun accès à la production, aucune inscription ni paiement. Les visuels de la page sont ceux du dépôt ; les vues sont cadrées sur la section concernée, sauf le début de page qui montre l'en-tête et le premier écran.
